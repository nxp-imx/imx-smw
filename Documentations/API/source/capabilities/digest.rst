Digest (Hash)
-------------

This section documents the hash/digest operations supported across different
security subsystems (ELE, TEE, SECO) with their respective algorithms.

.. Note::
   The digest multi-part support on **SECO** subsystem is calculated by SW and
   not by the Secure Enclave.

.. Note::
   SHAKE256 is an extendable-output function (XOF). The digest size can be
   any size greater than 0. The digest size shown is the default output length
   (64 bytes).
