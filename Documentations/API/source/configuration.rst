Library Configuration
=====================

The SMW Library configuration is split into two parts:

 - :ref:`Library Configuration <library-configuration>`: Defines how library
   is initialized to run in the OS environment.
 - :ref:`Subsystems Configuration <subsystems-configuration>`: Defines the
   mapping between Secure Subsystems and their supported operations.
