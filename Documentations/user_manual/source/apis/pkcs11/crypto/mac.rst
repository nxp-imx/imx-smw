Message authentication code (MAC)
"""""""""""""""""""""""""""""""""

PKCS#11 provides the same set of functions for message authentication code (MAC)
as for the asymmetric signature. Refer to the
:ref:`Asymmetric Signature<p11_asymmetric_signature>` section for the detailed
description of the operation sequences.

The operation initialization must be setup to use the asymmetric encryption
mechanisms as listed in the
:ref:`Message Authentication Code (MAC) Mechanisms<p11_mac_mechanims>`.
