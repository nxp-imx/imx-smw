.. _library-configuration:

Library Configuration
---------------------

The SMW Library allows user to configure the Secure Subsystems storage.
This includes the storage identification for the Secure Enclave (SECO or ELE)
and the Trusted Application (TA) identification for the TEE Secure Subsystem.
These settings are OS-dependent.

Hence it's handled by the :ref:`OSAL <osal>` module.
